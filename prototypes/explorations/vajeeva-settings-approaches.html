Settings & health-profile edit — 3 approaches
Today the More tab renders only a Sign Out button, so a user can never change the conditions they set during onboarding. Each approach adds name + health-profile editing to that tab a different way. All three reuse the onboarding condition grid and write the same healthProfile store that powers the “Safe for me” filter.
